# Fraud Detection —  Machine Learning

An interactive machine learning project that analyzes transaction patterns using Isolation Forest, XGBoost, and SHAP, with a Streamlit dashboard for visualizing suspicious activity and explaining model predictions.

## Features

- **Anomaly Detection** — Identifies unusual transaction patterns using Isolation Forest.
- **Machine Learning Classification** — Uses XGBoost to classify transactions based on anomaly-derived labels.
- **Explainable AI (XAI)** — Uses SHAP to interpret feature contributions to model predictions.
- **Interactive Dashboard** — Analyzes transactions through a Streamlit interface.
- **Feature Importance** — Visualizes the features influencing model predictions.
- **Data Visualization** — Generates SHAP summary plots, feature importance plots, and transaction-level analysis outputs.
- **End-to-End Pipeline** — Integrates preprocessing, anomaly detection, classification, and explainability.

## Getting Started

### Prerequisites

- Python 3.10 or higher
- pip
- Git

### Installation

```bash
git clone https://github.com/niharikamolagi03/Fraud--detection.git
cd Fraud--detection
```

### Create a Virtual Environment

For macOS or Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

For Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

If Streamlit or Plotly is not included in the requirements file, install the required packages:

```bash
pip install streamlit plotly
```

### Run the Machine Learning Pipeline

```bash
python main.py
```

The pipeline runs the preprocessing, anomaly detection, classification, and explainability steps configured in the project.

### Launch the Dashboard

```bash
streamlit run fraud_dashboard.py
```

Open the local URL displayed in the terminal, usually:

`http://localhost:8501`

## Key Components

### Anomaly Detection

Isolation Forest identifies transactions with unusual patterns in the available transaction data. These anomalies are used to generate candidate labels for subsequent classification.

### Machine Learning Classification

XGBoost learns patterns associated with the generated labels and produces predictions based on the features provided to the model.

### Explainable AI

SHAP estimates how individual features contribute to model predictions. The generated visualizations help interpret model behavior and investigate suspicious transaction patterns.

### Interactive Dashboard

The Streamlit dashboard provides an interface for transaction analysis and visualization of model outputs.

## Notes and Limitations

- An anomalous transaction is not necessarily fraudulent.
- Labels generated by Isolation Forest are not verified real-world fraud labels.
- Model performance against generated labels does not establish real-world fraud detection accuracy.
- SHAP explanations describe feature contributions to predictions; they do not prove fraudulent activity.
- The project is intended for learning, experimentation, and transaction risk analysis rather than validated production fraud detection.
